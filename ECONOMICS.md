# Economics — StackSpend

## Value proposition

- Show immediate savings potential so the user sees value before any email capture.
- Convert audit traffic into qualified leads for Credex.

## Cost structure

- Next.js hosting on Vercel.
- Supabase database and storage.
- Resend for transactional email.
- Anthropic API usage for executive summaries when enabled.

## Revenue logic

- The product is a lead-generation funnel, not a direct paid SaaS tool.
- The main economic win is moving users from retail AI spend to Credex-discounted credits.
- Higher audit conversion matters more than monetizing the audit itself.
